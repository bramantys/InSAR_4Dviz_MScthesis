Prototype2 · Parcel based · P2D10-R7A

Reference frame: Datum plane keeps the accepted apron and collar at Z=0. Cut block leaves every cap at the same data position inside a recessed excavation with a 50 m widened rim, a fixed visual floor, and an exterior Z=0 depth occluder; the floor and margin are not scientific data.

Irreversible reference: Model baseline preserves the source irreversible values. Selected date subtracts each parcel’s irreversible value at that date; it does not follow the current Studio segment.

Irreversible: permanent subsidence relative to the selected irreversible reference. Colour can show current displacement or long-term velocity.

Reversible: always shows the original date-specific R(t). It is not changed by the irreversible reference.

Total: referenced irreversible + original reversible R(t).

Combined: lower cap = referenced irreversible; upper cap = referenced irreversible + R(t). The gap between them always equals R(t).

Colour encoding: Cap and wall colours can be chosen independently where the active mode supports it. Irreversible and the lower Combined body use irreversible velocity or displacement; Reversible stays fixed to its zero-centred reversible scale; Total offers reversible, Total-displacement, or irreversible-velocity colour without changing height geometry.

Parcel inspection: D10B places the selected-parcel trendline with the epoch controls, keeps the isolated parcel mini viewer in the right drawer, and preserves the D8/D9 scientific interaction foundation. Trendline graph seeking remains scheduled for the post-layout correction.

Persistence: deformation mode, reference frame, irreversible reference date, per-mode exaggeration, and colour selections are stored locally in this browser. “Default” restores the controlled comparison baseline.

The reference ground is Z=0. It is clipped exactly around all parcel footprints in EPSG:28992. Town holes remain basemap windows, and the 0.12 m Combined render bias is only a depth-separation device.
