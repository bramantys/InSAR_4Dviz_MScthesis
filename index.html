Interactive CesiumJS webportal prototypes for InSAR data visualization. Recommended use: desktop or laptop browser with WebGL enabled.

Prototype1 - RUM based

New Prototype1 UI with one merged horizontal-particle mode switch: Monte Carlo realizations and uncertainty shimmer now live in the same viewer.

Jakarta Dual-mode viewer Jakarta Vertical Uncertainty V2 Groningen Dual-mode viewer Synthbowl Dual-mode viewer

Prototype2 - Parcel Based

Parcel-based 4D visualization of seasonal soft-soil deformation in Krimpenerwaard. The viewer separates reversible seasonal movement from irreversible long-term subsidence, showing parcels as animated vertical surfaces through time.

Krimpenerwaard Parcel viewer Krimpenerwaard - MC Parcel viewer

Local use

Online use requires no installation. For local use, download the repository and run a simple local server: 

python -m http.server 8000

Then open http://localhost:8000/.
