Template package

The Proto1_RUM_TEMPLATE/ folder contains the original reusable package structure and pipeline notes. It is not meant to be opened as a finished viewer.

The 4DViz_thesis/P1_4.1.5.V4_4D_MC_template/ folder contains the new version for Prototype1.

Local use

Online use requires no installation. For local use, download the repository and run a simple local server: 

python -m http.server 8000

Then open http://localhost:8000/.
