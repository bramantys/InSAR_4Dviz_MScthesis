# Supporting Tools

This folder contains helper scripts for preparing data and media
used with the Strapdown Visualizer (SDV) and
Parcel Deformation Visualizer (PDV).

## Linked Video Preparation

`prepare_sdv_pdv_linked_video.py`

Converts a source MP4 into three aspect-ratio variants
(16:9, 1:1, and 9:16) and generates a JSON manifest
containing video URLs and SHA-256 checksums.
